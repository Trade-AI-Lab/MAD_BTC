# Classifier_ai
The aim of this sub project is to learn what are the right data points compared to the all data points. We try to use AI in order to know if we should trust the strategy or not. We compare it according to the market.

For example, our strategy says to buy, and the market crashed down  , that means the data point is wrong while when the strategy says to sell and the market crashed down that means the data point is right. We would like an AI which finds the right and the wrong data points for a new strategy...
